# American Imperial University — Homepage Redesign

A responsive front-end concept redesign created as an internship selection task.

## Run locally
1. Download and extract the ZIP.
2. Open the `aiu-homepage-redesign` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension and select **Open with Live Server**.

## Files
- `index.html` — page structure and homepage content
- `styles.css` — layout, responsive styles and visual design
- `script.js` — mobile navigation and dynamic footer year

## Design direction
- Deep navy, warm ivory and muted gold palette
- Editorial serif headings paired with clean sans-serif body text
- Clear navigation and application calls to action
- Programme cards, student support, university introduction and admissions journey
- Responsive layout for desktop, tablet and mobile

## Content and implementation notes
Programme names, listed credit hours and durations are based on the university website at the time of the redesign. The homepage has been reorganised and copy has been edited for clarity; this is a design concept, not an official university publication.
The university's recognition, accreditation, membership and award claims should be checked against current official records before publication. This concept intentionally avoids presenting third-party memberships as equivalent to institutional accreditation.
Images are loaded from Unsplash and Google Fonts are loaded online, so an internet connection is needed for those assets.
